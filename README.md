# Story Generator

A single-page story generator. Pick a story structure, location, object and situation, and the app writes a short story from your choices.

## Live demo

Deployed on Vercel from the `jolaschool2023/marie` GitHub repository.

## Run locally

Open `index.html` in any browser. There is no build step and no dependencies.

## Structure

- `index.html` - the complete app (HTML, CSS and JavaScript in one file)
- `vercel.json` - static hosting configuration

## Technology

- Vanilla JavaScript
- Embedded CSS
- No frameworks, no build step, no backend
